# mBERT Sentiment Analysis Benchmark

Compares fine-tuning strategies for multilingual BERT on Punjabi, Urdu, and Roman Urdu sentiment datasets.

## Source

- [Fine_Tuning_mBERT_on_Punjabi.py](Fine_Tuning_mBERT_on_Punjabi.py)
- [Fine_Tuning_mBERT_on_Urdu.py](Fine_Tuning_mBERT_on_Urdu.py)
- [Fine_Tuning_mBERT_on_roman_urdu.py](Fine_Tuning_mBERT_on_roman_urdu.py)

## How to explore

Open the notebook export for your language in Colab or Jupyter. Install its listed dependencies, supply the CSVs referenced by that export, and run the selected experiment in order. GPU requirements depend on the fine-tuning method.
